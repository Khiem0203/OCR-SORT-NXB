# Dữ liệu thử

Thư mục này không đưa lên git (sách thật có bản quyền). Muốn chạy các script trong `test/get_*` thì tự chép vào đây mỗi cuốn một thư mục con, ví dụ:

```
test/data/sach_1/<tên sách>.pdf
test/data/sach_1/<tên sách>.docx   (nếu có)
test/data/sach_1/Bia 1.jpg          (nếu có)
test/data/audio_1/<file âm thanh>.mp3
```
